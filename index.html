学习路线

怎么学效果最好

  • 按顺序学。后面的章节会反复用到前面的概念（比如第 05 章的回测方法，贯穿之后所有模型的对比）。
  • 每个实验都动手调一调。先猜"把这个参数调大会怎样"，再拖滑块验证，比读十遍公式有用。
  • 每章结构一致：业务问题 → 直觉 → 互动实验 → 原理与公式 → Python 参考代码 → 常见坑 → 小测验。
  • 需要的基础：高中数学就够起步；会一点 Python 能更好地用上每章的参考代码。
关于数据和代码

页面里的业务数据都是按真实规律仿真生成的（固定随机种子，每次打开都一样），所以清洗和预测的效果可以和"真值"对比打分。页面内的算法是为教学手写的精简实现；真正上生产，请用每章给出的 Python 库（statsmodels、LightGBM、PyTorch 等）。
