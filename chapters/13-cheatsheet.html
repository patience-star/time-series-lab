公式速查

名称公式
加法 / 乘法分解$y_t = T_t + S_t + R_t$ 　/　 $y_t = T_t \times S_t \times R_t$
差分 / 季节差分$\nabla y_t = y_t - y_{t-1}$ 　/　 $\nabla_m y_t = y_t - y_{t-m}$
自相关系数$r_k = \dfrac{\sum_{t=k+1}^{n}(y_t-\bar y)(y_{t-k}-\bar y)}{\sum_{t=1}^{n}(y_t-\bar y)^2}$
简单指数平滑$\ell_t = \alpha y_t + (1-\alpha)\ell_{t-1}$，$\hat y_{T+h} = \ell_T$
Holt-Winters（乘法季节）$\ell_t = \alpha\frac{y_t}{s_{t-m}} + (1-\alpha)(\ell_{t-1}+b_{t-1})$；$b_t = \beta(\ell_t-\ell_{t-1})+(1-\beta)b_{t-1}$；$s_t = \gamma\frac{y_t}{\ell_t}+(1-\gamma)s_{t-m}$
AR(p)$y_t = c + \phi_1 y_{t-1} + \cdots + \phi_p y_{t-p} + \varepsilon_t$
MA(q)$y_t = \mu + \varepsilon_t + \theta_1\varepsilon_{t-1} + \cdots + \theta_q\varepsilon_{t-q}$
SARIMA$\phi(B)\,\Phi(B^m)\,(1-B)^d(1-B^m)^D\,y_t = \theta(B)\,\Theta(B^m)\,\varepsilon_t$
AIC$\text{AIC} = -2\log L + 2k$
回归树的切分增益$\sum_i (y_i-\bar y)^2 - \big[\sum_{左}(y_i-\bar y_{左})^2 + \sum_{右}(y_i-\bar y_{右})^2\big]$
GBDT$F_m(x) = F_{m-1}(x) + \eta\, h_m(x)$，$h_m$ 拟合残差 $y - F_{m-1}(x)$
梯度下降$w \leftarrow w - \eta\,\partial L/\partial w$
RNN$h_t = \tanh(W_x x_t + W_h h_{t-1} + b)$
LSTM$c_t = f_t\odot c_{t-1} + i_t\odot g_t$，$h_t = o_t\odot\tanh(c_t)$；$f,i,o = \sigma(\cdot)$，$g = \tanh(\cdot)$
缩放点积注意力$\text{Attention}(Q,K,V) = \text{softmax}\big(QK^{\top}/\sqrt d\big)V$
报童模型$q^* = F^{-1}\big(\tfrac{C_u}{C_u+C_o}\big)$
再订货点$\sum_{j=1}^{L}\hat y_{T+j} + z_\alpha\,\sigma_L$

评估指标速查

指标公式什么时候用小心
MAE$\frac1n\sum|\hat y_t-y_t|$单条序列，直观不同量级不可比
RMSE$\sqrt{\frac1n\sum(\hat y_t-y_t)^2}$大误差代价高对离群点敏感
MAPE$\frac1n\sum\big|\frac{\hat y_t-y_t}{y_t}\big|$业务沟通实际值近 0 时爆炸
WAPE$\frac{\sum|\hat y_t-y_t|}{\sum|y_t|}$零售、多序列汇总大销量主导
MASEMAE ÷ 训练集上季节朴素法的 MAE跨序列比较；<1 即优于朴素需要解释
Bias$\frac1n\sum(\hat y_t-y_t)$监控系统性高估/低估正负抵消
分位数损失$\tau(y-\hat q)^+ + (1-\tau)(\hat q-y)^+$评估分位数 / 区间—
覆盖率落在预测区间内的比例检验区间是否校准要和区间宽度一起看

继续学习

  • 《Forecasting: Principles and Practice》第 3 版（Hyndman & Athanasopoulos）——预测领域最好的入门书，全文免费在线：otexts.com/fpp3。本教程的统计部分与它的体系一致。
  • statsmodels 文档的时间序列部分：statsmodels.org
  • Nixtla 开源生态（statsforecast / mlforecast / neuralforecast）的教程，偏工程实践：nixtlaverse.nixtla.io
  • LightGBM 文档的参数调优指南：lightgbm.readthedocs.io
  • M 系列预测竞赛（M4、M5）的总结论文：了解"什么方法在大规模真实数据上真的有效"的最佳材料。
  • 想深入深度学习：先把 PyTorch 官方教程里的序列模型部分跑一遍，再读 PatchTST、DLinear 这两篇互相"对话"的论文。
最后的建议

找一份你自己业务里的真实数据，把这套流程完整走一遍：体检 → 清洗 → 画图 → 季节朴素基线 → ETS → GBDT → 滚动回测排行榜。走完一遍，比再读十篇教程都有用。
