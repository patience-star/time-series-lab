ARIMA 是时间序列统计建模的"教科书模型"：它把一条序列的规律拆成三块——自回归（AR）、差分（I）、移动平均（MA）。前面几章学的平稳性、差分、ACF/PACF 都是为它准备的。学完这一章，你能读懂 ARIMA(1,1,1)(0,1,1)7 这样的记号，知道每个数字是怎么定出来的，也知道它什么时候好用、什么时候该换别的方法。

三块积木

AR(p) · 自回归

今天的值 = 过去 p 天的值的加权和 + 新的冲击。刻画"惯性"。

I(d) · 差分

先做 d 次差分把序列变平稳，再建模。刻画"趋势"。

MA(q) · 移动平均

今天的值 = 新的冲击 + 过去 q 次冲击的余波。刻画"冲击的回声"。

ARIMA(p, d, q) 就是：对序列做 $d$ 次差分，然后用 $p$ 阶 AR 加 $q$ 阶 MA 来描述差分后的平稳序列。

⚠️ 别被名字误导

这里的"移动平均（MA）模型"和第 02 章的"移动平均平滑"不是一回事。平滑是对观测值求平均；MA 模型是对看不见的随机冲击做加权。只是历史上撞了名。

AR：今天像过去

$$y_t = c + \phi_1 y_{t-1} + \phi_2 y_{t-2} + \cdots + \phi_p y_{t-p} + \varepsilon_t$$

就是用自己的过去值做线性回归。$\phi$ 的大小决定惯性强弱；AR(2) 在特定参数下还会产生伪周期——没有固定周期的起伏（像经济景气循环）。平稳的条件是系数不能太大：AR(1) 要求 $|\phi_1|<1$；AR(2) 要求 $\phi_1+\phi_2<1$、$\phi_2-\phi_1<1$、$|\phi_2|<1$。

MA：冲击的回声

$$y_t = \mu + \varepsilon_t + \theta_1 \varepsilon_{t-1} + \cdots + \theta_q \varepsilon_{t-q}$$

$\varepsilon_t$ 是每一期新发生的随机冲击（意外的大单、一次物流延误）。MA(q) 说的是：一次冲击只会影响接下来的 q 期，之后彻底消失。这和 AR 不同——AR 里的冲击会以指数衰减的方式永远留下痕迹。

💼 业务里的 MA 现象
  • 一次临时促销把需求提前透支：当天多卖，之后两三天少卖（$\theta$ 为负）。
  • 仓库某天爆仓，积压的订单在随后两天陆续发出（$\theta$ 为正）。
  • 对数据做了差分之后，差分本身会引入 MA 结构——这是上一章差分实验里"滞后 1 负相关"的来源。

I：差分，以及几个你已经认识的特例

ARIMA 里的 "I"（Integrated）就是上一章的差分。有意思的是，前面学过的好几个方法其实都是 ARIMA 的特例：

ARIMA 记号等价于说明
ARIMA(0,0,0)白噪声（+ 均值）预测 = 均值法
ARIMA(0,1,0)随机游走预测 = 朴素法
ARIMA(0,1,0) + 常数带漂移的随机游走预测 = 漂移法
ARIMA(0,1,1)简单指数平滑$\alpha = 1 + \theta_1$
ARIMA(0,2,2)Holt 线性趋势
ARIMA(0,0,0)(0,1,0)m季节朴素法

所以 ARIMA 和指数平滑不是对立的两派，而是有很大重叠的两个家族：线性的指数平滑模型都能写成 ARIMA；反过来，ARIMA 有 AR 项和更灵活的阶数，而指数平滑有乘法季节这类非线性形式。

Box–Jenkins 建模流程

ARIMA 建模有一套经典的迭代流程，点击每一步查看。

ARIMA / SARIMA 拟合台

有季节的数据要用季节 ARIMA（SARIMA），记作 ARIMA$(p,d,q)(P,D,Q)_m$。大写的三个数是同样的三块积木，只是作用在季节滞后上：$P$ 是"和上个周期同一位置"的自回归，$D$ 是季节差分，$Q$ 是季节滞后上的冲击回声。

$$\underbrace{\phi(B)}_{\text{AR}}\;\underbrace{\Phi(B^m)}_{\text{季节 AR}}\;\underbrace{(1-B)^d}_{\text{差分}}\;\underbrace{(1-B^m)^D}_{\text{季节差分}}\;y_t \;=\; \underbrace{\theta(B)}_{\text{MA}}\;\underbrace{\Theta(B^m)}_{\text{季节 MA}}\;\varepsilon_t$$

$B$ 是"后移算子"：$B\,y_t = y_{t-1}$，$B^m y_t = y_{t-m}$。这个式子只是把"先差分、再 AR、右边 MA"紧凑地写在一行里。

🧪 实验：亲手拟合一个 ARIMA
残差的 ACF（应全部落在虚线带内）

默认是月度数据上经典的"航空模型" ARIMA(0,1,1)(0,1,1)₁₂。试着破坏它：① 把 D 调成 0、Q 调成 0——残差 ACF 在 12、24 处冒出高柱，Ljung-Box 报警，预测也丢了季节形状；② 把 d 调成 0——预测不再跟随趋势；③ 把 p、q 都加到 3——AIC 不降反升，测试误差也没改善：参数多不等于好。再换到"电商日销量"试试 (1,0,1)(0,1,1)₇：残差诊断合格，但测试误差未必能明显胜过季节朴素法（对比右边的基线 MAE）——训练数据里的促销尖峰是它看不见原因的"冲击"，会干扰估计和预测。本章后面的 ARIMAX 实验专门解决这个问题。

怎么看拟合结果
  • 残差 ACF + Ljung-Box：p 值 > 0.05 表示"看不出残差里还有规律"，模型合格；p 值很小说明还有结构没抓到，要改阶数。
  • AIC：越小越好，用于同一份数据、相同差分阶数的模型之间比较。
  • 预测区间随步长变宽：每多预测一步，就多累积一份未知的未来冲击。有差分（d ≥ 1）时区间会无限变宽；平稳模型的区间会收敛到一个固定宽度。
  • 测试集误差才是最终裁判：AIC 最低的模型未必预测最准。
原理补充：参数是怎么估计出来的 
给定一组系数 (φ, θ)，可以从头到尾"重放"一遍数据，递推出每一期的冲击：

    e_t = y_t − (φ1·y_{t-1} + … ) − (θ1·e_{t-1} + … )

e_t 就是"模型没预料到的部分"（一步预测误差）。

· 条件平方和（CSS）：找让 Σ e_t² 最小的系数            ← 本页面用的方法
· 极大似然（MLE）   ：假设 e_t 服从正态分布，找让数据出现概率最大的系数
                      （statsmodels 默认，用卡尔曼滤波精确计算）

两者在数据较长时结果几乎相同。因为 e_t 依赖 e_{t-1}（递归），目标函数对系数
不是二次的，没有解析解，只能用数值优化一步步搜索。

AIC = −2·log(似然) + 2·(参数个数)：拟合越好第一项越小，参数越多第二项越大。

自动定阶：让信息准则来选

看图定阶需要经验，而且 ARMA 混合模型的图往往读不出来。实际工作中更常用的是：差分阶数用检验确定，然后在一个网格里遍历 p 和 q，选 AIC 最低的。这就是 auto_arima 做的事。

🧪 实验：p × q 网格搜索

每个格子是一个模型的 AIC，颜色越深越好。通常能看到两个现象：好的模型不止一个——一片区域的 AIC 都差不多（这时选其中最简单的）；右下角参数最多的模型 AIC 并不是最低的。再对比"AIC 选出的模型"和"测试误差最低的模型"：它们常常不是同一个，但测试误差相差不大。

加入外部变量：ARIMAX / 动态回归

ARIMA 只用序列自己的历史，所以它不知道明天有促销。把外部变量加进来的标准做法是"回归 + ARIMA 误差"：

$$y_t = \beta_1 x_{1,t} + \cdots + \beta_k x_{k,t} + \eta_t,\qquad \eta_t \sim \text{ARIMA}$$

回归部分解释"促销让销量变成几倍"，剩下的 $\eta_t$（去掉事件影响后的日常波动）交给 ARIMA。预测时把未来的促销计划代进去即可。

🧪 实验：告诉模型"下周有促销"

测试段里有一次 3 天的小促。不带外部变量的 SARIMA 完全预见不到那个尖峰；勾选"加入促销日历"后，模型从历史上学到了各类活动的平均效应，并把它加到了对应的日子上。下面的表顺便给出了一个很有业务价值的副产品：每类活动的增量效应估计。

⚠️ 使用外部变量的前提
  • 预测时必须知道外部变量未来的值：促销计划、节假日可以；实际天气、竞品价格不行（只能用它们的预报，预报误差会传导进来）。
  • 回归系数是"平均效应"：假设每次小促的效果相同。促销力度差别大时，要用更细的特征（折扣深度、资源位），这正是下一章机器学习方法的强项。

优点、局限与使用建议

✅ 优点

理论成熟、可解释（每个系数都有含义）；自带预测区间和诊断工具；数据不长（几十到几百个点）也能用；短期预测很强。

⚠️ 局限

只能表达线性关系；只支持一个季节周期，且周期很长（日数据的年季节 m=365）时难以估计；每条序列单独建模，序列之间不能互相借力；对异常值和结构突变敏感。

🧭 什么时候用

序列数量不多、每条都重要（如公司级月度营收）；需要可解释和区间；作为机器学习/深度学习模型必须打败的强基线。

Python 参考代码：SARIMAX、诊断、自动定阶、外部变量 
import numpy as np
from statsmodels.tsa.statespace.sarimax import SARIMAX
from statsmodels.stats.diagnostic import acorr_ljungbox

train, test = np.log(y[:-28]), y[-28:]                 # 对数变换稳定方差

# ---------- 手动指定阶数 ----------
model = SARIMAX(train, order=(1, 0, 1), seasonal_order=(0, 1, 1, 7)).fit(disp=False)
print(model.summary())                                 # 系数、标准误、AIC
print(acorr_ljungbox(model.resid, lags=[14], model_df=3))   # 残差是否白噪声
model.plot_diagnostics(figsize=(10, 6))                # 残差图 / 直方图 / QQ 图 / ACF

fc = model.get_forecast(28)
mean = np.exp(fc.predicted_mean)                       # 逆变换回原尺度
band = np.exp(fc.conf_int(alpha=0.05))

# ---------- 自动定阶 ----------
import pmdarima as pm
auto = pm.auto_arima(train, seasonal=True, m=7, d=None, D=1,
                     max_p=3, max_q=3, max_P=1, max_Q=1,
                     information_criterion="aicc", stepwise=True, trace=True)
print(auto.order, auto.seasonal_order)

# 大批量序列用 statsforecast，速度快几个数量级
from statsforecast import StatsForecast
from statsforecast.models import AutoARIMA
sf = StatsForecast(models=[AutoARIMA(season_length=7)], freq="D", n_jobs=-1)

# ---------- 外部变量（促销、节假日） ----------
X_train, X_future = X[:-28], X[-28:]                   # 每列一个 0/1 事件标记；未来值必须已知
mx = SARIMAX(train, exog=X_train, order=(1, 0, 1), seasonal_order=(0, 1, 1, 7)).fit(disp=False)
fc_x = np.exp(mx.get_forecast(28, exog=X_future).predicted_mean)
print(np.exp(mx.params[:X.shape[1]]) - 1)              # 各事件的增量效应（百分比）

本章要点与小测验

  • AR = 对自己过去值的回归（惯性）；MA = 过去冲击的余波（回声）；I = 差分（趋势）。
  • AR(p)：ACF 拖尾、PACF p 阶截尾；MA(q)：ACF q 阶截尾、PACF 拖尾。
  • 朴素法、漂移法、SES、Holt 都是 ARIMA 的特例。
  • 流程：变换 → 差分至平稳 → 定阶 → 估计 → 残差诊断（应为白噪声）→ 预测。
  • SARIMA 的 $(P,D,Q)_m$ 是作用在季节滞后上的同一套积木。
  • AIC 在拟合优度和复杂度之间折中；最终以回测误差为准。
  • ARIMAX 用回归项引入促销、节假日等已知的未来信息。
