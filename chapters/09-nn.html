LSTM 和 Transformer 看起来复杂，但它们和最简单的神经网络共用同一套零件：神经元、损失函数、梯度下降、反向传播。这一章把这四个零件逐个拆开讲清楚，并在浏览器里现场训练一个小网络。下一章的 LSTM 只是把这些零件按另一种方式接起来。

神经元：加权求和，再过一个"开关"

一个神经元做两件事：把输入加权求和，再通过一个非线性的激活函数：

$$h = \sigma(w_1x_1 + w_2x_2 + \cdots + w_nx_n + b)$$

权重 $w$ 表示每个输入有多重要、往哪个方向起作用；偏置 $b$ 决定"门槛"在哪；激活函数 $\sigma$ 提供非线性——没有它，无论叠多少层，整个网络都只是一个线性回归。

🧪 实验：一个神经元能表达什么

w 控制曲线的陡峭程度和朝向（负的 w 让曲线翻转），b 让曲线左右平移。切换激活函数并留意虚线（导数）：sigmoid 的导数最大只有 0.25，而且两端几乎为 0——信号一旦落在"饱和区"，梯度就传不回去。这是下一章"梯度消失"的根源；ReLU 在正半轴导数恒为 1，所以深层网络普遍用它。

激活函数输出范围特点常见用途
sigmoid $\frac{1}{1+e^{-x}}$(0, 1)像一个平滑的开关；两端饱和LSTM 的"门"（0 = 关，1 = 开）；二分类输出
tanh(−1, 1)以 0 为中心；两端饱和RNN / LSTM 的状态更新
ReLU $\max(0,x)$[0, ∞)计算快；正半轴不饱和MLP、CNN、Transformer 的前馈层
线性（无激活）(−∞, ∞)—回归任务的输出层（预测值不该被压缩）

多层感知机（MLP）：很多个神经元叠起来

把一排神经元并列成一个隐藏层，再把它们的输出加权求和，就是最简单的神经网络——多层感知机：

$$\hat y = \sum_{j=1}^{H} v_j\,\sigma(w_j x + b_j) + c$$

每个隐藏神经元提供一个"基本形状"（一个 S 形台阶或一个折角），输出层把这些形状按不同权重叠加起来。神经元足够多时，这种叠加可以逼近任何连续函数——这就是"万能逼近定理"的直观含义。下面用上一章的"气温 → 负荷"数据现场训练，对比一下：树用阶梯去拟合，神经网络用平滑的曲线。

梯度下降：沿着下坡的方向一小步一小步走

训练就是找一组参数让损失函数最小。回归任务最常用的损失是均方误差 $L = \frac1n\sum(\hat y_i - y_i)^2$。参数有成千上万个，没法直接解方程，只能迭代：

$$w \leftarrow w - \eta\,\frac{\partial L}{\partial w}$$

梯度 $\partial L/\partial w$ 指向损失上升最快的方向，所以往反方向走；学习率 $\eta$ 是步长。

🧪 实验：学习率和优化器
损失曲面（一维）与参数的移动轨迹
损失随迭代步数的变化

这条损失曲线有两个谷：左边深（全局最优），右边浅（局部最优）。① 普通梯度下降、学习率 0.05：稳稳滑进右边的浅谷就不动了；② 学习率调到 0.6 以上：步子太大，在谷的两侧来回弹甚至飞出去；③ 换成"动量法"并把学习率调到 0.1 左右：像一个有惯性的球，冲过小山包滚进了更深的谷；④ Adam 会自动调节步长，学习率在很大范围内都能稳定收敛（但它同样可能停在局部最优）——对学习率不敏感是它成为默认选择的原因。

名词含义
批（batch）每次更新参数用的一小撮样本（如 32 个）。用小批量估计梯度又快又带点随机性，称为随机梯度下降（SGD）
轮（epoch）把全部训练样本过一遍
动量更新方向 = 当前梯度 + 上一步方向的一部分，减少来回震荡
Adam动量 + 每个参数各自的自适应步长（梯度一直很大的参数步子小一点）。深度学习的默认优化器
早停验证集误差不再下降就停止训练，防止过拟合

反向传播：梯度是怎么算出来的

梯度下降需要知道损失对每一个参数的偏导数。反向传播就是用链式法则高效地算出它们的方法：先从输入到输出算一遍（前向），再从损失开始，把"误差信号"一层一层往回传（反向）。每经过一个运算，就乘上这个运算的局部导数。

🧪 实验：一步一步走完前向和反向传播

反复点"下一步"。前向 5 步算出预测和损失；反向 4 步把梯度传回来——注意每一步都只用到"后一个节点的梯度"和"本节点的局部导数"，这就是链式法则。全部走完后点"更新参数"：三个参数各自沿负梯度走一小步，损失应该变小。再点几次，看损失一路下降。

为什么这很重要

反向传播里的梯度是连乘出来的。网络越深（或者序列越长），连乘的项越多：如果每一项都小于 1，梯度会指数级缩小——梯度消失，前面的层学不动；如果都大于 1，则梯度爆炸。下一章会看到，普通 RNN 正是栽在这里，而 LSTM 的设计就是为了给梯度修一条不会衰减的"高速公路"。

把时间序列喂给神经网络

和上一章一样用滑动窗口。区别在于：机器学习模型吃的是一张二维的表，而深度学习模型吃的是三维张量：

$$\text{输入形状} = [\,\text{样本数},\ \text{时间步数},\ \text{每步的特征数}\,]$$

比如"用过去 28 天、每天 3 个特征（销量、是否促销、星期几）预测未来 7 天"，输入就是 [N, 28, 3]，输出是 [N, 7]。MLP 不理解"时间步"这个维度，只能把 28×3 摊平成 84 个数；RNN/LSTM 则按时间顺序一步一步读。

⚠️ 神经网络对数据尺度很敏感：必须标准化
  • 把输入和目标都变换到 0 附近、量级为 1：常用 $(x-\mu)/\sigma$，销量类数据通常先取对数。
  • $\mu$ 和 $\sigma$ 只能用训练集计算，再应用到验证/测试集——用全量数据算就是泄漏。
  • 多条序列一起训练时，每条序列用自己的 $\mu,\sigma$（或每个窗口除以窗口内的均值）。
  • 预测完记得逆变换回原始尺度再算指标。
🧪 实验：用 MLP 预测明天的销量

输入是过去 14 天的销量（取对数、标准化），输出是明天的销量。训练几十轮后，网络自己发现了"看 7 天前"这个规律，误差降到季节朴素法附近或更低。它没有被告知任何关于"星期"的信息——规律完全是从窗口里的数值学出来的。下一章换成 LSTM，让网络按时间顺序读这 14 天。

Python 参考代码：PyTorch 的标准训练循环（之后所有模型都套这个模板） 
import numpy as np, torch, torch.nn as nn
from torch.utils.data import TensorDataset, DataLoader

# ---------- 数据：滑动窗口 + 只用训练段统计量做标准化 ----------
ly = np.log1p(y.values.astype("float32"))
n_train = len(ly) - 56
mu, sd = ly[:n_train].mean(), ly[:n_train].std()
z = (ly - mu) / sd

def windows(z, win=14, h=1):
    X = np.stack([z[i:i + win] for i in range(len(z) - win - h + 1)])
    Y = np.stack([z[i + win:i + win + h] for i in range(len(z) - win - h + 1)])
    return torch.tensor(X), torch.tensor(Y)

X, Y = windows(z)
split = n_train - 14                                  # 按时间切分
train = DataLoader(TensorDataset(X[:split], Y[:split]), batch_size=32, shuffle=True)
Xva, Yva = X[split:], Y[split:]

# ---------- 模型 ----------
model = nn.Sequential(nn.Linear(14, 32), nn.ReLU(), nn.Dropout(0.1), nn.Linear(32, 1))
opt = torch.optim.Adam(model.parameters(), lr=1e-3, weight_decay=1e-5)
loss_fn = nn.MSELoss()

# ---------- 训练循环：前向 → 损失 → 反向 → 更新；带早停 ----------
best, patience = float("inf"), 0
for epoch in range(200):
    model.train()
    for xb, yb in train:
        opt.zero_grad()
        loss = loss_fn(model(xb), yb)                 # 前向 + 损失
        loss.backward()                               # 反向传播：自动算出所有梯度
        opt.step()                                    # 梯度下降一步
    model.eval()
    with torch.no_grad():
        val = loss_fn(model(Xva), Yva).item()
    if val < best - 1e-4: best, patience = val, 0; torch.save(model.state_dict(), "best.pt")
    else:
        patience += 1
        if patience >= 15: break                      # 早停

model.load_state_dict(torch.load("best.pt", weights_only=True))
pred = np.expm1(model(Xva).detach().numpy() * sd + mu)   # 逆变换回原尺度

本章要点与小测验

  • 神经元 = 加权求和 + 激活函数；激活函数提供非线性。
  • MLP 用很多神经元的"基本形状"叠加出复杂函数。
  • 训练 = 用梯度下降最小化损失；学习率太大发散、太小太慢；Adam 是默认优化器。
  • 反向传播 = 链式法则；梯度是连乘出来的，所以会消失或爆炸。
  • 时序数据以 [样本, 时间步, 特征] 的三维张量输入；必须标准化，且统计量只能来自训练集。
  • 防过拟合：早停、Dropout、权重衰减、更多数据。
