指数平滑是工业界用得最广的预测方法之一：原理一句话就能说清（越近的数据越重要），计算快到可以给几十万个 SKU 每天各跑一遍，效果却常常不输复杂模型。这一章从最简单的版本出发，一步步加上趋势和季节，得到著名的 Holt-Winters 模型。

核心思想：给近期数据更大的权重

移动平均把窗口里的每个点一视同仁，窗口外的一律不看——这有点武断。更自然的想法是：所有历史都看，但越久远的权重越小，而且按固定比例递减：

$$\hat y_{T+1} = \alpha\,y_T + \alpha(1-\alpha)\,y_{T-1} + \alpha(1-\alpha)^2\,y_{T-2} + \cdots$$

权重 $\alpha,\ \alpha(1-\alpha),\ \alpha(1-\alpha)^2,\dots$ 呈指数衰减，所以叫指数平滑。参数 $\alpha\in(0,1)$ 控制"遗忘速度"。

简单指数平滑（SES）

上面那个无穷求和有一个极其简洁的递推写法——只需记住一个数，水平 $\ell_t$：

$$\ell_t = \alpha\,y_t + (1-\alpha)\,\ell_{t-1} \qquad\Longleftrightarrow\qquad \ell_t = \ell_{t-1} + \alpha\,(y_t - \ell_{t-1})$$

右边的写法更有启发性：新的估计 = 旧的估计 + α × 这次的预测误差。预测错了多少，就朝正确方向修正其中的 α 成。未来所有步的预测都等于最新的水平：$\hat y_{T+h} = \ell_T$（一条水平线），所以 SES 只适合没有趋势和季节的数据。

🧪 实验：α 是"灵敏"和"稳重"之间的旋钮
最近 20 个观测各自的权重

数据在第 60 天水平突然上了一个台阶。α 很小（0.05）：曲线很平滑，但要过很久才追上新水平；α 很大（0.9）：立刻追上，但也跟着每一次噪声上蹿下跳。切到"只有噪声"的数据：α 越小误差越低；有台阶的数据：α 太小反而误差大。没有通用的最佳 α，要让数据自己选（最小化一步预测误差）。

💼 业务里的 SES

很多监控系统和库存系统里的"指数加权移动平均（EWMA）"就是它。α = 0.1 大致相当于 19 天的移动平均（等效窗口 ≈ 2/α − 1），但不需要保存 19 天的数据——只存一个数，来一个新值更新一次，非常适合实时流式计算。

Holt 线性趋势：再记一个"斜率"

数据有趋势时，SES 的水平线预测会系统性落后。Holt 的办法是再维护一个状态——趋势 $b_t$（当前每步涨多少），并用同样的指数平滑方式更新它：

$$\begin{aligned} \text{水平：}\; & \ell_t = \alpha\,y_t + (1-\alpha)(\ell_{t-1} + b_{t-1})\\ \text{趋势：}\; & b_t = \beta\,(\ell_t - \ell_{t-1}) + (1-\beta)\,b_{t-1}\\ \text{预测：}\; & \hat y_{T+h} = \ell_T + h\,b_T \end{aligned}$$

预测是一条斜线。问题来了：现实中很少有东西能永远按当前速度涨下去。阻尼趋势（damped trend）给斜率乘一个小于 1 的系数 $\phi$，让趋势逐步衰减、预测曲线逐渐走平：

$$\hat y_{T+h} = \ell_T + (\phi + \phi^2 + \cdots + \phi^h)\,b_T$$
🧪 实验：线性外推 vs 阻尼趋势

数据是某个新功能的周活跃用户：前期高速增长，之后逐渐饱和（典型的 S 型增长）。站在高速增长期往后预测近一年：φ = 1（不阻尼）的预测一路直线冲上去，越远越离谱；把 φ 往下调，预测曲线逐渐走平，在某个位置和实际走势最接近；调得太小又会走平得太早。大量实证研究表明，阻尼趋势在长步长预测上通常更稳妥，是自动预测系统的默认选项之一——但它不是万能的：对持续稳定增长的数据，线性趋势反而更准（见下面 ETS 实验里的月度销售额）。

Holt-Winters：水平 + 趋势 + 季节

再加第三个状态——每个季节位置一个季节系数 $s_t$，就得到 Holt-Winters。三个状态各有一个平滑参数：$\alpha$（水平）、$\beta$（趋势）、$\gamma$（季节）。乘法季节版本：

$$\begin{aligned} \text{水平：}\; & \ell_t = \alpha\,\frac{y_t}{s_{t-m}} + (1-\alpha)(\ell_{t-1} + b_{t-1})\\ \text{趋势：}\; & b_t = \beta\,(\ell_t - \ell_{t-1}) + (1-\beta)\,b_{t-1}\\ \text{季节：}\; & s_t = \gamma\,\frac{y_t}{\ell_t} + (1-\gamma)\,s_{t-m}\\ \text{预测：}\; & \hat y_{T+h} = (\ell_T + h\,b_T)\times s_{T+h-m} \end{aligned}$$

读法：先把今天的值除掉季节再去更新水平；用水平的变化更新趋势；用"今天的值 ÷ 水平"更新这个位置的季节系数。加法版本把除号换成减号、乘号换成加号。它其实就是把第 02 章的"分解"做成了在线、自适应的版本：每来一个新数据，三个成分各自微调一点。

🧪 实验：Holt-Winters 调参台
模型学到的季节系数（训练结束时）

先手动拧一拧：γ 调到 0 时季节系数永远停在初始值；α 调得很大，拟合线几乎贴着数据走，但预测未必更准。然后点"自动寻优"，看三个参数怎么一步步收敛到让一步预测误差最小的位置。再做两个对比：① 在"电商日销量"上把趋势从"阻尼"切到"线性"再寻优——训练段末尾刚好有一次小促，线性趋势把它当成了"开始上涨"并一路外推，测试误差大幅变差；② 在"月度销售额"上对比加法和乘法季节：乘法的预测会随水平放大季节波动，更贴合实际。

💡 参数的典型取值与含义
  • α 大（>0.5）：水平变化快，数据接近随机游走；α 小：水平稳定，波动多是噪声。
  • β 通常很小（0–0.1）：趋势变化缓慢。β 寻优到 0 表示趋势基本恒定。
  • γ 小：季节形状稳定；γ 大：季节形状在变（比如用户的周内习惯在迁移）。
  • 初始状态（第一个周期的水平、趋势、季节）也会影响结果，数据短时尤其明显；成熟的库会把初始状态一起优化。

ETS 家族：自动选型

趋势可以是"无 / 加法 / 阻尼"，季节可以是"无 / 加法 / 乘法"，组合起来就是一个模型家族；再考虑误差是加法还是乘法，就是统计学里的 ETS（Error-Trend-Seasonal）框架。SES、Holt、Holt-Winters 都是其中的特例。ETS 框架带来两个好处：有了明确的概率模型，可以推导预测区间；可以用信息准则（AICc）在家族里自动选型。

🧪 实验：九种组合，谁最适合这份数据

表格是九种组合在留出的测试段上的误差（每种都已自动寻优参数），高亮的是当前选中的组合。切换趋势和季节类型，看预测形状如何变化：没有季节项的预测是一条直线或缓弯的线；没有趋势项的预测在原地重复季节形状。自动选型（AutoETS）做的就是把这张表算一遍，只不过它用训练集上的 AICc 而不是测试误差来选。

数据特征推荐组合常用名字
无趋势、无季节趋势 无 · 季节 无简单指数平滑 SES
有趋势、无季节趋势 阻尼 · 季节 无阻尼 Holt
季节幅度固定趋势 加法/阻尼 · 季节 加法加法 Holt-Winters
季节幅度随水平放大（最常见）趋势 加法/阻尼 · 季节 乘法乘法 Holt-Winters

优点、局限与使用建议

✅ 优点

快、稳、参数少且可解释；几十个数据点就能用；自带预测区间；对缺失少、规律稳定的序列效果常常接近最优。

⚠️ 局限

不能加入外部变量（促销、价格、天气）；只支持一个季节周期；对异常值敏感（会把尖峰吸收进水平和季节系数）；长周期季节（m=365）不适用。

🧭 什么时候用

大批量序列的自动预测；作为强基线；数据短、无协变量的场景。有明显促销效应时，要么先清洗事件，要么换第 08 章的特征模型。

Python 参考代码：SES / Holt / Holt-Winters / AutoETS 
from statsmodels.tsa.holtwinters import ExponentialSmoothing, SimpleExpSmoothing
from statsmodels.tsa.exponential_smoothing.ets import ETSModel

train, test = y[:-28], y[-28:]

# 简单指数平滑
ses = SimpleExpSmoothing(train).fit()                  # 自动寻优 alpha
print(ses.params["smoothing_level"])

# Holt-Winters：阻尼趋势 + 乘法季节
hw = ExponentialSmoothing(train, trend="add", damped_trend=True,
                          seasonal="mul", seasonal_periods=7).fit()
fc = hw.forecast(28)
print(hw.params)                                       # alpha / beta / gamma / phi

# ETS 状态空间版本：带预测区间
ets = ETSModel(train, error="mul", trend="add", damped_trend=True,
               seasonal="mul", seasonal_periods=7).fit(disp=False)
pred = ets.get_prediction(start=len(train), end=len(train) + 27)
band = pred.summary_frame(alpha=0.05)                  # mean, pi_lower, pi_upper

# 成千上万条序列：statsforecast 的 AutoETS（自动选型，速度极快）
from statsforecast import StatsForecast
from statsforecast.models import AutoETS, SeasonalNaive
sf = StatsForecast(models=[AutoETS(season_length=7), SeasonalNaive(7)], freq="D", n_jobs=-1)
fc_all = sf.forecast(df=long_df, h=28, level=[80, 95])  # long_df: unique_id, ds, y

本章要点与小测验

  • 指数平滑 = 对历史做指数衰减的加权平均；递推形式是"旧估计 + α × 误差"。
  • SES 管水平，Holt 加趋势，Holt-Winters 再加季节；每个状态一个平滑参数。
  • 阻尼趋势让长期预测逐渐走平，通常比线性外推更稳妥。
  • 季节幅度随水平变化用乘法季节。
  • 参数由数据通过最小化一步预测误差来确定；ETS 框架还能自动选型并给出预测区间。
  • 不能用外部变量、只能一个季节周期，是它的主要局限。
