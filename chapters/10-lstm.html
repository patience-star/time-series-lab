MLP 把一个窗口的数据"摊平"后一口吞下，并不知道哪个数在前哪个在后。循环神经网络（RNN）换了一种读法：像人读句子一样，按时间顺序一步一步读，边读边更新脑子里的"记忆"。LSTM 是 RNN 中最成功的一种，它用三个"门"解决了普通 RNN 记不住长期信息的问题，至今仍是时间序列深度学习里最常用的基础模型。

RNN：带记忆的神经网络

RNN 维护一个隐藏状态 $h_t$——可以理解为"读到目前为止的摘要"。每来一个新输入，就用它和旧的摘要一起算出新的摘要：

$$h_t = \tanh\!\big(W_x\,x_t + W_h\,h_{t-1} + b\big)$$

关键点有两个：

  • 同一组参数在每个时间步重复使用（参数共享）。所以序列多长都能处理，参数量也不随长度增加。
  • $h_t$ 依赖 $h_{t-1}$，$h_{t-1}$ 又依赖 $h_{t-2}$……所以理论上 $h_t$ 包含了之前所有输入的信息。
🧪 实验：只有一个神经元的 RNN，怎么"记住"过去

输入是两周的销量（已标准化）。隐藏状态 h 的更新规则是 ht = tanh(0.6·xt + w·ht−1)。把"记忆权重 w"调到 0：h 只反映当天的输入，没有记忆；调到 0.9：h 变成过去很多天的平滑混合——这很像指数平滑！区别是：指数平滑的 α 由人定公式，RNN 的权重是从数据里学出来的，而且有很多个这样的神经元，各自学会记不同的东西。

RNN 的致命伤：梯度消失

训练 RNN 用的是"沿时间反向传播"（BPTT）：把展开后的网络当成一个很深的网络做反向传播。误差信号从最后一步往回传，每经过一个时间步，就要乘一次 $W_h$ 和 tanh 的导数：

$$\frac{\partial h_T}{\partial h_t} = \prod_{k=t+1}^{T} W_h^{\top}\,\mathrm{diag}\big(1-h_k^2\big)$$

这是 $T-t$ 个矩阵的连乘。tanh 的导数不超过 1，权重通常也不大，于是连乘的结果随距离指数级缩小：30 步之前的输入对损失的梯度可能只剩 $10^{-10}$，等于"学不到"。反过来权重偏大时会指数级放大——梯度爆炸（这个容易处理，裁剪梯度即可）。

🧪 实验：误差信号往回传，能传多远

纵轴是对数刻度：每下降一格，梯度缩小到十分之一。① RNN 的权重尺度在 0.5 附近（常见的初始化）时，梯度几乎是一条直线向下——指数衰减；② 把权重尺度调大，衰减会变慢，但很难恰好调到"不衰减"——权重一大，tanh 就进入饱和区，导数变小，又把梯度压了回去（没有 tanh 压着的情况下则会指数爆炸）；③ 看 LSTM：把"遗忘门偏置"调大（遗忘门越接近 1），它的线越来越平——LSTM 可以把梯度几乎无损地传回很多步之前。为什么能做到，下一节揭晓。

LSTM：给记忆修一条"传送带"

LSTM（Long Short-Term Memory，长短期记忆）的核心想法：除了隐藏状态 $h_t$，再加一条专门存放长期记忆的通道——细胞状态 $c_t$。细胞状态像一条传送带，信息在上面只做简单的"乘一个系数、加一点新东西"，不经过层层压缩，所以可以原样保留很久。往传送带上放什么、拿掉什么、读出什么，由三个门控制。

每个时间步的计算（$z = [x_t, h_{t-1}]$ 表示把当前输入和上一步隐藏状态拼在一起）：

$$\begin{aligned} f_t &= \sigma(W_f z + b_f) &&\text{遗忘门：旧记忆每一项保留多少（0 = 全忘，1 = 全留）}\\ i_t &= \sigma(W_i z + b_i) &&\text{输入门：新信息每一项写入多少}\\ g_t &= \tanh(W_g z + b_g) &&\text{候选记忆：这一步想写入的新内容}\\ c_t &= f_t \odot c_{t-1} + i_t \odot g_t &&\textbf{更新细胞状态：忘掉一部分旧的，加上一部分新的}\\ o_t &= \sigma(W_o z + b_o) &&\text{输出门：记忆里的哪些部分现在要用}\\ h_t &= o_t \odot \tanh(c_t) &&\text{隐藏状态：对外输出} \end{aligned}$$

$\odot$ 是逐元素相乘。门都用 sigmoid，因为它的输出在 0–1 之间，正好表示"开多大"。

为什么这样就不怕梯度消失了

看第 4 行：$c_t = f_t \odot c_{t-1} + \cdots$。从 $c_t$ 到 $c_{t-1}$ 的梯度就是 $f_t$——只乘一个遗忘门，没有权重矩阵，也没有 tanh 的压缩。只要网络学会把遗忘门开到接近 1，梯度就能沿着细胞状态这条传送带几乎无损地传回很多步。而且遗忘门是学出来的、随输入变化的：网络可以自己决定什么时候该记住（$f\approx1$），什么时候该清空（$f\approx0$）。

🧪 实验：亲手拧三个门

这里把三个门固定在某个开度上，观察一个记忆单元 40 步内的表现。输入在第 5 步和第 22 步各有一次脉冲（候选记忆 g）。试试预设：长期记住（f = 1）——第一次脉冲被一直保存；快速遗忘（f = 0.6）——记忆几步内衰减，像短期的指数平滑；屏蔽输入（i = 0）——新信息写不进去；记着但不说（o = 0）——细胞状态里存着，但隐藏状态输出为 0。真实的 LSTM 里，这三个开度每一步都由网络根据当前输入重新计算。

现场训练一个 LSTM

下面在浏览器里训练一个真正的 LSTM 来预测电商销量：读入过去若干天，一次输出未来 7 天（多输出策略）。数据做了对数变换和标准化；训练集、验证集、测试集按时间先后切分。

⚠️ 诚实地说：单条序列上，LSTM 往往打不过简单方法

上面的实验只有一条序列、几百个训练样本。在这种数据量下，LSTM 的表现通常和季节朴素法、指数平滑差不多，甚至更差——这是大量预测竞赛反复验证过的结论，不是这个演示的问题。深度学习的优势在于"很多条相关序列一起训练"（成千上万个 SKU、门店、设备）加上丰富的协变量。那时它能学到单条序列学不到的共性规律。

长依赖任务：RNN 与 LSTM 的正面对比

设计一个专门考"记忆力"的任务：序列的第 1 步给出一个数值（并带一个"请记住"的标记），之后的若干步全是无关的噪声，最后一步要求把最初的那个数值原样输出。要做对，模型必须把第 1 步的信息一直保存到最后。

🧪 实验：记住 N 步之前的一个数

纵轴是 R²：1 表示完美复述，0 表示和瞎猜（输出均值）一样。间隔设为 5–8 步时，两种网络都能学会；拉到 20 步以上，RNN 的曲线通常趴在 0 附近起不来——梯度传不回第 1 步，它根本不知道该记住什么；LSTM 则在若干轮之后"开窍"，学会了只在有标记的那一步打开输入门、之后保持遗忘门接近 1，把那个数一直存在细胞状态里。（两个网络都只有 8 个隐藏单元；RNN 用常见的小权重初始化，LSTM 的遗忘门偏置初始化为 2，即默认倾向于"记住"——这是实践中的常用技巧。网络很小、训练轮数有限，偶尔会有例外；点"重新训练"会换一组随机初始权重。）

GRU 与参数量

GRU（Gated Recurrent Unit）是 LSTM 的简化版：把遗忘门和输入门合并成一个"更新门"，去掉了单独的细胞状态，只有两个门。参数比 LSTM 少四分之一，训练更快，效果通常相近。两者谁更好没有定论，实践中都试一下即可；讲原理时以 LSTM 为准，因为它的"传送带"更直观。

🧪 参数量计算器

循环层的参数量 ≈ 门的个数 × 隐藏单元数 × （输入维度 + 隐藏单元数 + 1）。注意它和序列长度无关（参数共享），而和隐藏单元数的平方成正比——把隐藏单元翻倍，参数量大约变成 4 倍。训练样本只有几百上千个时，几十个隐藏单元就足够了。

Python 参考代码：PyTorch LSTM 多步预测（含协变量、早停、梯度裁剪） 
import numpy as np, torch, torch.nn as nn
from torch.utils.data import TensorDataset, DataLoader

WIN, H = 28, 7                                    # 看 28 天，预测 7 天

class LSTMForecaster(nn.Module):
    def __init__(self, n_feat, n_future_feat, hidden=64, layers=1, dropout=0.1):
        super().__init__()
        self.lstm = nn.LSTM(n_feat, hidden, num_layers=layers, batch_first=True,
                            dropout=dropout if layers > 1 else 0.0)
        self.head = nn.Sequential(nn.Linear(hidden + H * n_future_feat, 64), nn.ReLU(),
                                  nn.Dropout(dropout), nn.Linear(64, H))
    def forward(self, x_hist, x_future):
        # x_hist: [B, WIN, n_feat]      历史窗口（目标值 + 协变量）
        # x_future: [B, H, n_future_feat] 未来已知的协变量（促销计划、星期等）
        _, (h_n, _) = self.lstm(x_hist)           # h_n[-1]: [B, hidden] 最后一步的隐藏状态
        z = torch.cat([h_n[-1], x_future.flatten(1)], dim=1)
        return self.head(z)                       # [B, H]

def make_windows(z, feats, fut):                  # z: 标准化后的目标；feats/fut: 协变量矩阵
    Xh, Xf, Y = [], [], []
    for t in range(WIN, len(z) - H + 1):
        Xh.append(np.column_stack([z[t - WIN:t], feats[t - WIN:t]]))
        Xf.append(fut[t:t + H]); Y.append(z[t:t + H])
    f32 = lambda a: torch.tensor(np.array(a), dtype=torch.float32)
    return f32(Xh), f32(Xf), f32(Y)

ly = np.log1p(y)
n_tr = len(ly) - 112                              # 最后 16 周：8 周验证 + 8 周测试
mu, sd = ly[:n_tr].mean(), ly[:n_tr].std()        # 只用训练段统计量
Xh, Xf, Y = make_windows((ly - mu) / sd, feats, fut)
i_va, i_te = n_tr - WIN, n_tr - WIN + 56
train = DataLoader(TensorDataset(Xh[:i_va], Xf[:i_va], Y[:i_va]), batch_size=64, shuffle=True)

model = LSTMForecaster(Xh.shape[2], Xf.shape[2])
opt = torch.optim.Adam(model.parameters(), lr=1e-3, weight_decay=1e-5)
best, bad = 1e9, 0
for epoch in range(300):
    model.train()
    for xh, xf, yb in train:
        opt.zero_grad()
        loss = nn.functional.mse_loss(model(xh, xf), yb)
        loss.backward()
        nn.utils.clip_grad_norm_(model.parameters(), 1.0)      # 梯度裁剪
        opt.step()
    model.eval()
    with torch.no_grad():
        val = nn.functional.mse_loss(model(Xh[i_va:i_te], Xf[i_va:i_te]), Y[i_va:i_te]).item()
    if val < best: best, bad, state = val, 0, {k: v.clone() for k, v in model.state_dict().items()}
    else:
        bad += 1
        if bad >= 20: break                                    # 早停
model.load_state_dict(state)
pred = np.expm1(model(Xh[i_te:], Xf[i_te:]).detach().numpy() * sd + mu)

本章要点与小测验

  • RNN 按时间顺序读序列，用隐藏状态传递记忆；每一步共用同一组参数。
  • 普通 RNN 的梯度沿时间连乘、指数衰减，学不到长距离依赖。
  • LSTM 增加了细胞状态（传送带）和三个门：遗忘门决定留多少旧记忆，输入门决定写多少新信息，输出门决定读出多少。
  • 细胞状态的梯度只乘遗忘门，遗忘门接近 1 时梯度几乎不衰减。
  • GRU 是更轻的变体；参数量与序列长度无关，与隐藏单元数的平方成正比。
  • 实务：标准化、窗口覆盖季节周期、早停、梯度裁剪；LSTM 的价值主要体现在多序列全局训练上。
