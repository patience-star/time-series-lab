预测的前提是"过去的规律在未来仍然成立"。平稳性就是这句话的数学版本。这一章讲清楚三件事：什么样的序列是平稳的、不平稳时怎么用差分把它变平稳、以及怎么用 ACF / PACF 这两张图读出一条序列的"记忆结构"——它们是下一步学 ARIMA 的全部预备知识。

平稳性：规律不随时间漂移

一条序列是（弱）平稳的，指它的统计性质不随时间改变：

  • 均值恒定——没有趋势，围绕一个固定水平波动；
  • 方差恒定——波动幅度前后一致，没有喇叭口；
  • 自相关只取决于间隔——"今天和昨天的关系"在去年和今年是一样的。

直觉上：从平稳序列里任意截两段出来，你分辨不出哪段在前、哪段在后。有趋势、有季节、波动越来越大的序列都不平稳——而业务数据几乎全是这样。所以我们不指望原始数据平稳，而是通过变换把它变成平稳的，在平稳的部分上建模，再变换回去。

💼 为什么业务分析也要懂这个

两条都在增长的指标（比如"公司员工数"和"App 日活"）相关系数可以高达 0.9，但这不代表招人能涨日活——它们只是都在随时间增长。不平稳的序列之间会出现大量虚假的相关，下面第三个实验会让你亲眼看到。

三种基本过程：白噪声、AR(1)、随机游走

用一个最简单的公式就能造出三种性格完全不同的序列：

$$y_t = c + \phi\, y_{t-1} + \varepsilon_t,\qquad \varepsilon_t \sim \text{独立的随机冲击}$$
$\phi$名字性格最佳预测
$0$白噪声完全没有记忆，每一步都是独立的均值（没有任何可利用的规律）
$0<\phi<1$平稳 AR(1)有记忆但会遗忘：偏离均值后逐渐被拉回来（均值回复）介于当前值和均值之间，越远越靠近均值
$1$随机游走永不遗忘：每次冲击都永久保留，没有"应该回到的水平"就是当前值（明天最可能等于今天）
$>1$爆炸过程偏离被不断放大现实中很少持续存在
🧪 实验：把 φ 从 0 拧到 1

选"30 条"同时看很多条路径：φ 小于 1 时，所有路径被圈在一条固定宽度的带子里（平稳）；φ 拧到 1 的瞬间，带子变成不断张开的喇叭口——随机游走的不确定性随时间无限增大。再给一点"漂移"，随机游走就有了趋势：这就是很多业务指标"趋势 + 随机游走"的样子。

两个贯穿全课的结论
  • 好模型的残差应该是白噪声。如果残差里还有规律，说明模型没把能预测的部分榨干（第 07 章用这个标准做诊断）。
  • 随机游走的最佳预测是"和现在一样"。股价接近随机游走，所以任何模型都很难显著打败"明天价格 = 今天价格"。遇到这种数据，诚实的做法是承认它不可预测，把精力放在估计波动范围上。

伪回归：两条毫无关系的序列为什么"高度相关"

生成两条完全独立的随机游走，算它们的相关系数。按理说应该接近 0——真的吗？

多点几次"换一对"。独立白噪声的相关系数老老实实挤在 0 附近；独立随机游走的相关系数却铺满了 −1 到 1——随便抓两条有趋势的序列，都很可能"强相关"。解药是先差分再算相关：差分后的相关系数立刻回到 0 附近。分析"指标 A 是否驱动指标 B"时，请看变化量之间的相关，而不是水平之间的相关。

差分与变换：把序列变平稳

三种工具，各管一种不平稳：

问题工具公式含义
波动随水平放大取对数（或 Box-Cox）$y'_t = \log y_t$把"乘法"变"加法"，稳定方差
趋势一阶差分$\nabla y_t = y_t - y_{t-1}$从"水平"变成"变化量"
季节季节差分$\nabla_m y_t = y_t - y_{t-m}$和上个周期同一位置比（就是"同比变化量"）

取对数再做一阶差分有一个漂亮的解释：$\log y_t - \log y_{t-1} \approx$ 增长率。所以"对数差分"建模，实际上是在对增长率建模。

以"月度销售额"为例按顺序操作：① 什么都不做——趋势明显，ACF 缓慢衰减，ADF 判定不平稳；② 勾选取对数——喇叭口消失；③ 一阶差分——趋势没了，但 ACF 在 12、24 处有尖峰，季节还在；④ 再做季节差分——趋势和季节的尖峰都没了，只在滞后 1 和滞后 12 附近留下一两根负柱子。这不是没处理干净，而是差分留下的正常痕迹，第 07 章 ARIMA 里的 MA 项专门用来刻画它。然后把一阶差分调到 2 次：滞后 1 的自相关变得很负、标准差反而变大——这是差分过头的信号。

⚠️ 差分不是越多越好
  • 绝大多数业务序列：一阶差分 0–1 次、季节差分 0–1 次就够了，合计很少超过 2 次。
  • 差分过头的表现：滞后 1 自相关接近 −0.5，方差比差分前更大。
  • 差分会损失"水平"信息；预测完要记得逆变换回原尺度（累加回去、再取指数）。
  • 数据里有 0 或负值时不能直接取对数：可以用 $\log(1+y)$，或改用 Box-Cox / 不做变换。

平稳性检验：ADF 与 KPSS

肉眼判断之外，可以用统计检验给一个更客观的结论。最常用的两个检验的原假设正好相反，搭配使用最稳妥：

检验原假设 $H_0$怎么读
ADF（单位根检验）有单位根 → 不平稳统计量比临界值更负（或 p < 0.05）→ 拒绝 $H_0$ → 平稳
KPSS平稳p < 0.05 → 拒绝 $H_0$ → 不平稳

ADF 的做法是做一个回归：$\Delta y_t = \alpha + \gamma\, y_{t-1} + \sum_i \delta_i \Delta y_{t-i} + \varepsilon_t$。如果序列会"被拉回均值"，那么当前值越高、下一步的变化就越倾向于负，$\gamma$ 显著小于 0；随机游走则 $\gamma = 0$。检验统计量就是 $\gamma$ 除以它的标准误（上面实验里显示的就是它，5% 临界值约为 −2.86）。

ADFKPSS结论怎么办
平稳平稳平稳直接建模
不平稳不平稳有单位根差分
不平稳平稳数据太短或趋势平稳，证据不足结合图形判断，通常差分
平稳不平稳差分平稳差分
⚠️ 检验的三个盲区
  • ADF 看不见季节。一条有强季节但没有趋势的序列会被判"平稳"，仍需结合 ACF 判断是否做季节差分。
  • 结构突变会骗过检验。有一个水平台阶的平稳序列常被误判为不平稳（第 03 章的口径突变）。
  • 样本量很大时，一点点偏离也"显著"。检验是参考，不是判决；最终以回测效果为准。

ACF 与 PACF：读出序列的记忆结构

自相关函数 ACF 回答："今天和 $k$ 天前有多像？"——就是第 02 章滞后图里的相关系数，对每个 $k$ 都算一遍：

$$r_k = \frac{\sum_{t=k+1}^{n}(y_t-\bar y)(y_{t-k}-\bar y)}{\sum_{t=1}^{n}(y_t-\bar y)^2}$$

偏自相关函数 PACF 回答一个更精细的问题："排除掉中间那几天的传话之后，今天和 $k$ 天前还有没有直接关系？"

举个例子：如果今天只直接受昨天影响（AR(1)，$\phi=0.8$），那今天和前天仍然相关（$0.8^2=0.64$）——但那是通过昨天"传话"过来的。ACF 把这种间接相关也算进去，所以缓慢衰减；PACF 把它剔除，所以只有滞后 1 那一根柱子。

Python 参考代码：检验、差分、ACF / PACF 
import numpy as np
from statsmodels.tsa.stattools import adfuller, kpss
from statsmodels.graphics.tsaplots import plot_acf, plot_pacf

def check_stationarity(x, name=""):
    x = x.dropna()
    adf_stat, adf_p, *_ = adfuller(x, autolag="AIC")
    kpss_stat, kpss_p, *_ = kpss(x, regression="c", nlags="auto")
    print(f"{name:12s} ADF={adf_stat:6.2f} (p={adf_p:.3f})  KPSS p={kpss_p:.3f}  "
          f"=> {'平稳' if adf_p < 0.05 and kpss_p > 0.05 else '不平稳/证据不足'}")

ly = np.log(y)                       # 稳定方差
d1 = ly.diff()                       # 一阶差分 ≈ 增长率
d1s = ly.diff().diff(12)             # 再做季节差分（m=12）

for name, x in [("原始", y), ("对数", ly), ("对数差分", d1), ("再季节差分", d1s)]:
    check_stationarity(x, name)

plot_acf(d1s.dropna(), lags=36)      # 看季节尖峰是否消失
plot_pacf(d1s.dropna(), lags=36, method="ywm")

# 自动判断需要几次差分
from pmdarima.arima import ndiffs, nsdiffs
print(ndiffs(ly, test="adf"), nsdiffs(ly, m=12))

本章要点与小测验

  • 平稳 = 均值、方差、自相关结构不随时间变；预测模型在平稳的部分上才学得到可靠规律。
  • 白噪声不可预测；随机游走的最佳预测是当前值；平稳 AR 会向均值回复。
  • 两条不平稳的序列很容易出现虚假的高相关——先差分再谈相关。
  • 取对数稳方差，一阶差分去趋势，季节差分去季节；差分过头会让方差变大、滞后 1 自相关变得很负。
  • ADF 的原假设是"不平稳"，KPSS 的原假设是"平稳"；两个都看不见季节。
  • ACF 看总相关，PACF 看排除中间传话后的直接相关；两张图合起来是序列的"指纹"。
